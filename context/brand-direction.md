# TEELA DIGITAL — BRAND DIRECTION

## 1. Brand Overview

### Brand Name

**Teela Digital**

This is the official and final company name.

### Official Brand Lockup

**TEELA DIGITAL**

*Ideas, engineered beautifully.*

**Digital Product & Software Company**

The brand lockup establishes the company's name, primary tagline, and category descriptor.

### Tagline

**Ideas, engineered beautifully.**

This is Teela Digital's official tagline.

**Digital Product & Software Company**

The descriptor clearly communicates what Teela Digital is without limiting the company to website development.

**Ideas deserve to be built well.**

This is the underlying philosophy behind the brand.

The tagline, **Ideas, engineered beautifully.**, is the outward-facing expression of this philosophy.

# 12. Colour System

### Primary Palette

| Token | Value | Usage |
|---|---|---|
| Off White | `#F7F7F4` | Primary background |
| Obsidian | `#111111` | Primary dark background / text |
| Charcoal | `#1A1A1A` | Secondary dark surfaces |
| White | `#FFFFFF` | Text on dark surfaces |
| Soft Grey | `#D9D9D4` | Borders / dividers |
| Mid Grey | `#8A8A84` | Secondary text |
| Accent Yellow | `#F2C94C` | Accent / interaction / highlights |

### Colour Rules

- Off White should be the primary light background.
- Obsidian should be used for strong contrast and dark sections.
- Yellow should be used sparingly.
- Yellow should function as an accent rather than becoming the dominant brand colour.
- Avoid unnecessary gradients.
- Avoid excessive colour variation.
- Maintain strong contrast and accessibility.

The colour system should feel restrained, editorial, and modern.

# 14. Typography Scale

Use a responsive type system rather than fixed desktop-only sizes.

Example:

```css
--text-xs: 0.75rem;
--text-sm: 0.875rem;
--text-md: 1rem;
--text-lg: 1.25rem;
--text-xl: 1.75rem;
--text-2xl: 2.5rem;
--text-3xl: 4rem;
--text-hero: clamp(4rem, 10vw, 9rem);
```

Hero typography should be large, confident, and responsive.

Typography should create hierarchy without requiring excessive decoration.

# 16. Layout

The layout should be:

- Editorial
- Grid-based
- Spacious
- Asymmetric where appropriate
- Responsive
- Content-led

Use a strong grid system with intentional alignment.

Large areas of whitespace are encouraged.

Do not fill empty space simply because it exists.

Whitespace should be treated as part of the design.

---

# 17. Border Radius

Use restrained corner rounding.

Preferred values:

- Small elements: `4px`
- Cards / controls: `8px`
- Larger containers: `16px`

Avoid excessive pill-shaped UI unless the component specifically requires it.

The overall interface should feel structured rather than overly soft.

---

# 18. Shadows

Use shadows sparingly.

The visual system should rely primarily on:

- Typography
- Contrast
- Spacing
- Borders
- Composition
- Colour
- Motion

Avoid heavy floating-card aesthetics.

---

# 19. Motion Direction

Motion should feel:

- Smooth
- Slow
- Premium
- Intentional
- Subtle
- Responsive

Motion should reinforce hierarchy and interaction rather than distract from content.

### Brand Motion Principle

> **Motion should communicate, not decorate.**

### Page Load

Use subtle entrance animations for major sections.

Example:

- Opacity: `0 → 1`
- Translate Y: `30px → 0`
- Duration: approximately `700–900ms`
- Use appropriate easing

### Scroll Reveal

Sections and content can reveal progressively as they enter the viewport.

Avoid revealing every small element independently.

### Parallax

Use subtle parallax effects for selected imagery or visual elements.

Avoid excessive movement.

### Marquee

A restrained marquee may be used to communicate Teela's capabilities.

Example:

**DESIGN — RESEARCH — ENGINEERING — DIGITAL PRODUCTS**

The marquee should remain secondary to the actual content.

### Hover Interactions

Project and interactive elements may use:

- Slight image scaling
- Title movement
- Arrow movement
- Yellow accent indicator
- Metadata reveal
- Subtle opacity changes

### Navigation

Navigation transitions should feel smooth and deliberate.

Mobile navigation should open and close with a controlled transition.

### Reduced Motion

All motion must respect:

```css
prefers-reduced-motion
```

Users who request reduced motion should receive a simplified or static experience.

# 25. Accessibility

Accessibility is part of the design system.

Ensure:

- Sufficient colour contrast
- Keyboard navigation
- Visible focus states
- Accessible form labels
- Semantic HTML
- Alternative text where appropriate
- Reduced-motion support
- Readable typography
- Responsive layouts
- Touch-friendly interaction targets

Do not sacrifice usability for visual aesthetics.

# 26. Responsive Design

The brand system must work across:

- Large desktop
- Standard desktop
- Tablet
- Mobile

The visual hierarchy should remain strong at every breakpoint.

Mobile should not simply be a compressed version of desktop.

Layouts, spacing, typography, imagery, and motion should be intentionally adapted for smaller screens.
